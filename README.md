# Share Care Give

A modern web application for creating sustainable funding for non-profits through community partnerships.

## Overview

Share Care Give connects local businesses with non-profit organizations through the Swipe It Forward program, which redirects credit card processing fees to support community causes at no additional cost to businesses.

## Features

- **Swipe It Forward Program**: Redirects credit card processing fees to local non-profits
- **Community Impact Tracking**: Fundraising meters show progress in each community
- **Interactive Map**: Explore communities where Share Care Give is making a difference
- **Testimonials**: Real feedback from businesses and non-profits
- **Responsive Design**: Fully optimized for all device sizes
- **Accessibility**: ARIA-compliant components for inclusive user experience

## Tech Stack

- React
- TypeScript
- React Router
- TailwindCSS
- Vite

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/share-care-give.git
cd share-care-give
```

2. Install dependencies
```bash
npm install
# or
yarn install
```

3. Start the development server
```bash
npm run dev
# or
yarn dev
```

4. Build for production
```bash
npm run build
# or
yarn build
```
